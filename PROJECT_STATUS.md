# Состояние проекта

## Готово

- Исходное PWA-приложение с десятью миссиями.
- Одиночный, семейный и классный режимы.
- Озвучка и локальные иллюстрации миссий.
- Работа без интернета после загрузки.
- Автономная сборка для запуска на Windows.
- Набор автоматических тестов.
- Репозиторий приведён к единому стандарту проектов.
- Стартовая заставка адаптирована под узкие экраны без обрезания названия.
- Множественный выбор сохраняет видимые отметки и озвучивает каждый выбранный вариант.
- Неверный вариант в множественном выборе показывает «БУМ!» и объяснение,
  не попадая в набор правильных ответов.
- В одиночных вопросах каждый выбранный вариант использует свою аудиореплику.
- Обновления приложения автоматически заменяют старый кеш и применяются без ручной очистки браузера.
- Критические модули вопроса №4 загружаются с номером сборки и не заменяются
  устаревшей копией из обычного кэша браузера.
- В миссии «Сообщение от папы» озвучка варианта В вопроса №4 называет верную
  букву, а каждый неправильный ответ получает соответствующее ему пояснение.
- В миссиях №3–10 найденные неоднозначные неправильные ответы получают
  отдельные пояснения, соответствующие выбранному варианту.
- Изменение настроек приложения обрабатывается одним обработчиком без
  повторного запуска одной и той же команды.

## Текущая техническая точка

- Исходники находятся в `src/`.
- Готовый пакет находится в `dist/`.
- Автоматическая проверка запускается для изменений в GitHub.
- В `.agents/skills/` подключены проектные Superpowers и Playwright; правила их
  обязательного применения при исправлении ошибок закреплены в `AGENTS.md`.
