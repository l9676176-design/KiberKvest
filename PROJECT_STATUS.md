# Состояние проекта

## Готово

- Исходное PWA-приложение с десятью миссиями.
- Одиночный, семейный и классный режимы.
- Озвучка и локальные иллюстрации миссий.
- Работа без интернета после загрузки.
- Автономная сборка для запуска на Windows.
- Набор автоматических тестов.
- Репозиторий приведён к единому стандарту проектов.

## Текущая техническая точка

- Исходники находятся в `src/`.
- Готовый пакет находится в `dist/`.
- Автоматическая проверка запускается для изменений в GitHub.

## Следующие изменения

Фиксируются здесь после отдельного согласования с владельцем проекта.
