КИБЕРКВЕСТ — АВТОНОМНЫЙ ЗАПУСК
Версия 2026.10.24

1. Полностью распакуйте архив в обычную папку.
2. Дважды щёлкните start-kiberkvest.cmd.
3. Приложение откроется в браузере: http://127.0.0.1:4173/.
4. В этом архиве уже есть все 10 миссий, картинки и русские записи. Внешний интернет для их прохождения не нужен, включая первый запуск.
5. Пока играете, оставляйте окно локального сервера открытым.
6. Для остановки закройте окно сервера или нажмите Ctrl+C.

Если Node.js отсутствует, его необходимо предварительно установить. Запуск на реальном Windows-компьютере ещё требует проверки.

Для веб-версии: перед отключением интернета откройте «Загрузки и обновления» и нажмите «Скачать все миссии». Дождитесь статуса «Скачана: картинки и озвучка» у каждой миссии. Установка одной иконки приложения сама по себе не скачивает все миссии.

Выключатель «Звук» в настройках отключает все реплики и фанфару.

Приложение не запрашивает имя, телефон, почту и другие персональные данные ребёнка. В нём нет открытого чата, рейтингов и платежей.
