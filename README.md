# КиберКвест

Автономное обучающее PWA-приложение с десятью интерактивными миссиями по цифровой безопасности для детей.

## Быстрый запуск исходной версии

```bash
npm start
```

Приложение откроется по адресу `http://127.0.0.1:4173/`.

## Проверка

```bash
npm test
```

## Основные разделы

- `src/` — исходный код, экраны, данные и материалы миссий.
- `tests/` — автоматические проверки.
- `dist/` — готовая автономная сборка.
- `scripts/` — сервер и сценарий сборки.
- `docs/` — подробная документация.

Полная схема приведена в [`docs/PROJECT_STRUCTURE.md`](docs/PROJECT_STRUCTURE.md), текущее состояние — в [`PROJECT_STATUS.md`](PROJECT_STATUS.md).

Файл `README.txt` сохранён как инструкция для пользователя автономного пакета.
