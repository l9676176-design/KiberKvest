# KiberKvest: правила продолжения

## Источник требований

- `research.md` — исследование, сценарии десяти миссий и утверждённые визуальные требования.
- `brief.md` — обязательный пошаговый план, экраны, переходы и критерии готовности.

## Границы

- Работать только внутри этой папки.
- Не устанавливать зависимости: приложение использует HTML, CSS, JavaScript и встроенный Node.js test runner.
- Не добавлять регистрацию детей, чат, рейтинги, платежи, Telegram как обязательную платформу или генеративный ИИ.
- Не публиковать проект и не отправлять его в GitHub без отдельного разрешения владельца.
- Не заменять утверждённые изображения без отдельного согласования.

## Команды

- Все тесты: `node --test tests/*.test.mjs tests/*.spec.mjs`
- Сборка: `powershell -ExecutionPolicy Bypass -File scripts/build-offline.ps1`
- Локальный запуск исходной версии: `node scripts/server.mjs`
- Локальный запуск собранной версии: из `dist` выполнить `node server.mjs`

## Структура

- `app/` — исходное PWA-приложение.
- `tests/` — проверки данных и поведения без сторонних библиотек.
- `dist/` — готовая статическая сборка.
- `downloads/KiberKvest-offline.zip` — автономный школьный пакет.
