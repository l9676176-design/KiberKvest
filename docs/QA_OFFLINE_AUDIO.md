## Автоматические проверки

`npm test`: 58 проверок, 58 успешных, 0 ошибок.
Новые регрессии сначала воспроизвели отсутствие MP3 в загрузке, ненастоящую
отмену, принятие HTML вместо медиа, ложный статус скачанной миссии, отсутствие

пакета при неудачном обновлении и восстановление после закрытия вкладки.

## Настоящий браузер

Chromium 145, Linux, окно 390×844. Использованы настоящие Cache Storage,
service worker, HTMLAudioElement и декодер AudioContext. Работа без сети
проверена одновременно отключением сети браузера и отказом испытательного
сервера отвечать: одна симуляция offline не гарантирует блокировку запросов worker.

Проверены:

- первый запуск и отсутствие ложных отметок «Скачана»;
- миграция старых загрузок из картинок;
- отмена и ошибка загрузки с отражением реального состояния;
- загрузка 446 файлов: 80 картинок и 366 MP3 миссий;
- восстановление и отмена прерванного обновления без потери старого пакета;
- повторное открытие без сети;
- декодирование всех 366 записей без сервера;
- полное прохождение десяти миссий, всех 80 страниц и 50 вопросов без сети;
- реальный запуск очереди с индивидуальным пояснением неправильного ответа;
- остановка уже играющего звука выключателем;
- запрет звука для выбора ответа, повтора сцены, вопроса, варианта и системной реплики;
- сохранение выключенного звука при перезапуске и возвращение звука после включения;
- отсутствие обращения к системному речевому синтезатору в проверенных сценариях;
- отсутствие необработанных ошибок приложения.

Локальный школьный пакет отдельно проверен при `navigator.onLine=false`,
но доступном сервере на 127.0.0.1: первый запуск, картинка и декодирование новой
индивидуальной записи. Этот сценарий сначала воспроизвёл блокировку первого
запуска, после исправления прошёл.
