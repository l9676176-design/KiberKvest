# Тестирование

Запуск всех проверок:

```bash
npm test
```

Тесты проверяют:

- целостность десяти миссий;
- наличие изображений и аудиофайлов;
- маршруты, экраны и режимы;
- настройки, загрузки и игровой прогресс;
- автономный кэш и PWA-манифест;
- адаптивные стили;
- устройство автономного пакета;
- утверждённую структуру репозитория.

GitHub повторяет эту команду автоматически при отправке изменений и создании запроса на объединение.

## Регрессии автономного звука

`tests/offline-download-regression.test.mjs` проверяет сохранение MP3 вместе
с изображениями, отказ при HTML вместо медиа, отмену, сохранность предыдущего
пакета, восстановление после закрытия вкладки и глобальное выключение звука.
Проверяются production-функции; подменяется только граница браузерных Cache/Audio API.

Реальный браузер дополнительно обязателен: полностью скачать миссии, запретить
серверу отвечать и отключить сеть браузера, перезапустить приложение, пройти миссии
и воспроизвести записи. Одного `context.set_offline(True)` недостаточно: запросы
service worker в Chromium иногда всё ещё доходят до сервера.
