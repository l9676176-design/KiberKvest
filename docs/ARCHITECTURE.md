# Архитектура

КиберКвест — браузерное PWA-приложение без серверной базы данных и внешних библиотек.

```text
Локальный сервер
      ↓
src/index.html
      ↓
Экраны + игровая логика + данные миссий
      ↓
Service Worker сохраняет приложение для работы без интернета
      ↓
Настройки и прогресс хранятся локально в браузере
```

`src/` является единственным источником разработки. `dist/` создаётся из `src/` сценарием `scripts/build-offline.ps1` и представляет готовый пакет.
