# Локальный запуск

## Требования

- Актуальная версия Node.js.
- Дополнительные зависимости не требуются.

## Запуск

```bash
git clone https://github.com/l9676176-design/KiberKvest.git
cd KiberKvest
npm start
```

Откройте `http://127.0.0.1:4173/`.

Чтобы не открывать браузер автоматически:

```bash
node scripts/server.mjs --no-open
```
