# Решение 001: использовать `src/` как папку исходного приложения

## Решение

Переименовать прежнюю папку `app/` в `src/` и использовать её как единственный источник разработки.

## Причина

Это соответствует утверждённому единому стандарту проектов и ясно отделяет исходники от готовой сборки `dist/`.

## Совместимость

Пути в сервере, сценарии сборки и тестах обновляются одновременно. Содержимое приложения при переносе не изменяется.
