# Безопасность

- Приложение не запрашивает имя, телефон, электронную почту и другие персональные данные ребёнка.
- В проекте нет чата, рейтингов и платежей.
- Прогресс и настройки сохраняются локально в браузере пользователя.
- Секреты, токены, пароли и настоящие файлы `.env` запрещено коммитить.
- Любое подключение внешнего сервера или сбора данных требует отдельного проектного и юридического согласования.
